# Collapsible

Unstyled Radix collapsible: shows and hides a region under a trigger.

- **Parts:** `Collapsible` (`open`, `defaultOpen`, `onOpenChange`), `CollapsibleTrigger` (`asChild`), `CollapsibleContent`.
- Animate the content with `overflow-hidden data-[state=open]:animate-collapsible-down data-[state=closed]:animate-collapsible-up`.
- A whole card section uses `CollapsibleCard`.

Source: `packages/frontend/src/components/ui/collapsible.tsx`.
