# Popover

Radix popover for small detail or a compact control beside its trigger: 288px wide, `popover` surface, 16px padding, `shadow-md`.

- **Parts:** `Popover`, `PopoverTrigger` (`asChild`), `PopoverContent` (`align`, `sideOffset` 4 by default).
- Anything with a submit button belongs in a `Dialog`. A one-line label belongs in a `Tooltip`.

Source: `packages/frontend/src/components/ui/popover.tsx`.
