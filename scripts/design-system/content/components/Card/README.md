# Card

The raised container: `card` surface, `radius-lg`, a hairline `border` and `shadow-sm`, with 24px padding in its parts.

- **Parts:** `Card`, `CardHeader` (title and description stack), `CardTitle` (an h2; the app sets `text-base`), `CardDescription`, `CardContent`, `CardFooter`.
- Use cards for discrete modules such as performers or trade stats. Heroes (Net Worth, Portfolio total) stay borderless, and Settings uses flat sections with separators.
- Avoid grids of identical cards. Size modules by importance.

Source: `packages/frontend/src/components/ui/card.tsx`.
