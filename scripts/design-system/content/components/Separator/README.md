# Separator

A 1px `border`-coloured rule, horizontal or vertical (Radix Separator, decorative by default).

- **You provide:** `orientation` ("horizontal" or "vertical"), and `decorative={false}` when it carries meaning for screen readers.
- Settings sections are an `h2` plus a `Separator`, not cards. In the app header a 24px vertical separator divides control groups.

Source: `packages/frontend/src/components/ui/separator.tsx`.
