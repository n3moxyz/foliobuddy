# App icons

Raster exports of `logo.svg` on its `mark-ground` tile. Regenerate all four whenever the mark changes.

- `apple-touch-icon.png` — 180 × 180, the iOS home-screen icon linked from `index.html` (the favicon does not control it).
- `icon-192.png`, `icon-512.png` — PWA manifest icons, purpose "any".
- `icon-maskable-512.png` — PWA maskable icon, with the mark inside the safe zone.

The web manifest pairs them with background colour `mark-ground` and theme colour dark `background`.
