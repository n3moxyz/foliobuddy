# User-Facing Inventory And Acceptance Criteria

This is the source-backed checklist for the production-scale local QA pass. It should be used with
`docs/qa/local-production-scale-runbook.md` and updated when user-facing routes, controls, fields,
or workflows change.

## Source Map

- SPA routes: `packages/frontend/src/App.tsx`
- Shell, navigation, keyboard shortcuts: `components/layout/*`, `hooks/useKeyboardShortcuts.ts`
- API client routes used by the UI: `packages/frontend/src/lib/api.ts`
- Backend route implementations: `packages/backend/src/routes/*`
- Scale seed: `packages/backend/src/scripts/seed-scale.ts`

## Rerun Evidence Required For A Clean Pass

For each route above, capture:

- browser route and viewport;
- dataset counts visible in the UI;
- actions exercised, including cancel paths for destructive modals;
- console errors/warnings after known non-actionable warnings are filtered;
- failed network requests and API status codes;
- screenshot or text evidence for each bug;
- shared-cause analysis, code fix, regression test, and rerun result.

The goal is not complete until this inventory has been run against the sanitized local database, all
bugs found during that pass are fixed with regression tests, and the inventory rerun is clean.
