# Historical production deployments

This record assigns versions after the fact, from v1.0.0 through v1.67.0. The About screen first reads the package version in v1.67.1.

The baseline is the earliest Vercel production deployment still on record. Vercel recorded a successful CLI build without a source commit.
GitHub recorded 317 successful Vercel production deployments and 24 failed attempts.
The table also includes 93 successful backend workflow runs. Runs with the same source commit share a version.

The backfill uses minor bumps for compatible features. It uses patch bumps for fixes, polish, documentation and operations changes.
The available history does not establish a breaking public contract change. The versions therefore stay in the 1.x series.
The change column uses the source commit subject. Some older GitHub records abbreviate the subject.

The records cover successful production deployments visible in [GitHub Deployments](https://github.com/n3moxyz/foliobuddy/deployments),
[Vercel](https://vercel.com/n3mos-projects/foliobuddy/deployments), and the
[backend workflow](https://github.com/n3moxyz/foliobuddy/actions/workflows/deploy-backend.yml).
Earlier Railway and manual deployments may be missing from the retained history.
